# list-shape recordings

Empty until `gi-probe capture` ships with `astra-game-launcher` 0.5.0. Each
recording is one game folder's listing in the launcher's list-shape format
(`bin/list-shape`, merged plan R29), named `<store>-<id>.json`, and ingest
replays every recording against a foundation's descriptor to fill
`descriptor-too-broad` and the probe-result evidence an `M_ADOPT_ENGINE_CODE`
act may cite.
